## 使用

### TUI

下載程式碼
```
git clone https://github.com/TW0hank0/positive_password_book.git
```

建立venv

```
uv venv
```

用uv安裝依賴

```
uv sync --extra tui
```

執行程式

```
uv run launch_tui.py
```
